# UPM 安装器

**Tools &gt; YKYToolkit &gt; UPM Installer** 可以在不离开编辑器的情况下安装、移除和更新 UPM 包。

## 两栏布局

左栏是当前操作使用的包列表；右栏存放已保存的包列表以及列表生成器。

## 工具栏

| 按钮                                                                        | 操作                                   |
|-----------------------------------------------------------------------------|----------------------------------------|
| インストール (Install)                                                      | 安装左栏中的所有包。                   |
| 削除 (Remove)                                                               | 移除左栏中的包。                       |
| 更新 (Update)                                                               | 查询注册表，并把有新版本的包加入列表。 |
| クリア (Clear)                                                              | 清空左栏。                             |
| 更新を確認し、すべてのUPMパッケージをアップグレードする (Check and upgrade) | 升级所有已安装的包。                   |
| メーカーにインポートする (Import to maker)                                  | 把左栏内容复制到右侧的生成器。         |

## 已保存的包列表

每个已保存的列表都有一个名称，以及任意数量的 `name@version` 条目。

- 展开某一行即可查看并编辑其中的包。
- **インポート** 把选中的列表添加到左栏。
- **選択した項目を削除** 移除该列表。
- 右键点击某一行，可以将其复制为 JSON 或删除。
- 列表按项目存储在 `EditorPrefs` 中，因此重启后仍然存在，但不会进入版本控制。

## 生成器

生成器是用于新建已保存列表的工作区：添加包条目，然后输入名称并按下 **作成してコピー** (Create and copy)。该列表会被保存，并以
JSON 形式复制到剪贴板，因此可以分享或提交到仓库。

## 包版本号的写法

条目由 `packageName` 加上可选的 `version` 组成。版本留空表示最新的兼容版本；指定版本则会锁定该确切发行版。与 UPM
一样，列表接受来自注册表、Git 和本地路径的包。
