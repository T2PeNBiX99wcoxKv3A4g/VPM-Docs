# 安裝

用 ALCOM、VPM CLI，或把儲存庫加入專案來安裝 `io.github.ykysnk.yky-toolkit`。套件相依於 `io.github.ykysnk.utils` 與
`io.github.ykysnk.localization`，VPM 會一併安裝。

## 安裝之後

視窗會出現在 **Tools &gt; YKYToolkit** 底下：

- UPM Installer
- Import Watcher and Import Watcher Settings
- Delete History
- Unity Resource Monitor
- Transform Expression Help
- Preferences
- Clear Shader Cache, Force Clear Temp Files, Clear Empty Folder, Allow Async Compilation
- Discord SDK Initialize / Restart / Shutdown

右鍵動作會加入 **GameObject &gt; YKYToolkit**、**Assets &gt; YKYToolkit** 與組件選單。

## 選用：lilEditorToolbox

安裝 `jp.lilxyzw.editortoolbox` 之後，工具組會透過它匯入 `.unitypackage` 檔案。沒有它時，工具組會退回 Unity 自己的匯入器，其他一切不變。
