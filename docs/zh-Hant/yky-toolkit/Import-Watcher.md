# 匯入監看器

**Tools &gt; YKYToolkit &gt; Import Watcher** 會記錄 Unity 執行期間匯入了哪些資產，每次編輯器執行對應一個工作階段，並依日期與時間分組。

## 記錄

左欄列出工作階段的日期，中欄是匯入時間，選取時間後右側以樹狀顯示對應的資產。

- **搜尋** 會依名稱或路徑篩選記錄。
- **重新整理** 會重新讀取目前的工作階段。
- **清除** 會在確認後清空匯入記錄。
- **設定** 開啟下文所述的設定視窗。
- 每個日期資料列會顯示其中有多少筆記錄。
- 資產以圖示與名稱顯示；工具提示中是完整路徑，資產已不存在的項目會以紅色顯示。
- 在資料列上按右鍵可複製路徑或移除。

## 醒目提示

匯入的資產會在 Project 視窗中短暫上色，因此大量匯入時不必盯著記錄也能掌握進度：

- **醒目提示顏色** 是覆蓋在資產上的顏色。
- **醒目提示持續時間** 是它停留的時間，單位為毫秒；預設為 120，滑桿最長到 500。
- **副檔名的醒目提示顏色** 讓每個副檔名擁有自己的顏色，因此匯入 `.unitypackage` 與 `.cs` 檔案的樣子不同。清單可重新排序，**恢復預設值** 會還原內建的組合，沒有對應項目的副檔名則使用預設顏色。

圖示檢視會以副檔名顏色框住整個儲存格，清單檢視則在資料列下方畫一條底線。收到檔案的資料夾也會一併醒目提示，而且顏色是逐漸淡出，不是瞬間消失。

## 設定

**Tools &gt; YKYToolkit &gt; Import Watcher Settings** 會開啟一個含有這些設定的小視窗；相同的值也位於 **Edit &gt; Preferences &gt; YKY Toolkit &gt; Import Watcher**。

| 設定                     | 效果                                             |
|--------------------------|--------------------------------------------------|
| 醒目提示顏色             | 在 Project 視窗中覆蓋於匯入資產上的顏色。         |
| 醒目提示持續時間         | 醒目提示停留的時間，單位為毫秒。                 |
| 最大歷史工作階段數       | 歷史保留多少個編輯器工作階段。                   |
| 副檔名的醒目提示顏色     | 醒目提示使用的各副檔名顏色，附有數量與重設按鈕。 |

區段標題旁的重設按鈕會還原內建的值。所有設定都以使用者為單位存放在 `EditorPrefs`，因此不會被提交。

## 刪除歷史

Unity 刪除資產時不會通知任何人。刪除歷史視窗會列出本次工作階段中被刪除（或刪除後又重新建立）的路徑，讓被刪掉的 `.meta`
或搬移過的資料夾能夠找回來。**Tools &gt; YKYToolkit &gt; Delete History** 可開啟它；[偏好設定](./Preferences.md)中的
**最大記錄數** 會限制保留多少筆項目。
