# Transform 檢視器

工具組會用一個能做算術、對齊物件與鎖定 transform 的檢視器取代預設的 Transform 檢視器。所有數值仍然會經過 `Undo`，因此
`Ctrl+Z` 可以還原先前的 transform。

## 局部空間與世界空間

**局部空間** 與 **世界空間** 兩張卡片會以該空間顯示位置、旋轉與縮放。每張卡片都有作用於整張卡片的複製、貼上、隨機與重設按鈕，
每一列也針對自己的屬性重複相同的動作。縮放列上的連結按鈕可切換比例約束。

多選時，相同的值只顯示一次，物件之間不同的值則顯示 `—`。

## 表達式

每個欄位都接受表達式，不只是數字：

```
2 + 3          -> 5
10 / 4         -> 2.5
1.5 * 2        -> 3
```

按下 Enter 套用：結果會寫入每個選取的物件，欄位則恢復成單純的數字。輸入時，欄位下方會出現相符表達式的清單；`↑`／`↓`
選擇項目，Enter 或 Tab 插入。單獨按 `Tab` 仍然是在欄位之間移動。

## 說明

**Tools &gt; YKYToolkit &gt; Transform Expression Help** 會開啟速查表，包含每個表達式、其寫法與範例，並分為基本算術、多選時的
排列與隨機值三組。搜尋框可依語法、別名或說明篩選，點擊資料列即把它的範例複製到剪貼簿。

## 剪貼簿

| 動作                    | 效果                                                       |
|-------------------------|------------------------------------------------------------|
| 複製／貼上（標題列）    | 該卡片的位置、旋轉與縮放。                                 |
| 資料列按鈕              | 該列的單一屬性。                                           |
| 在欄位上按右鍵          | **複製歐拉角**、**複製四元數** 與 Unity 自己的選單項目。    |

剪貼簿使用 Unity 自己的 `Vector3(…)` 與 `Quaternion(…)` 文字，因此這些值也能貼到 Unity 的預設欄位與其他工具中。

## 對齊

**對齊模式** 會選擇 **對齊至地面** 使用的參考：軸心、物件邊界的底部或中心。

- **對齊至父物件** 會把物件移到父物件的位置。
- **對齊至地面** 會向下對第一個不是物件本身或其子物件的碰撞體投射射線，忽略觸發器與 `Ignore Raycast` 圖層，並把物件放在命中點上。
- **清除父物件** 會保留世界位置並移除父物件。在預製體階段中無法使用。

## 其他

- **鎖定變換** 會停用該物件檢視器的所有欄位與動作。鎖定會以隱藏的 `EnhancedTransformSettings` 組件按物件儲存，只有在設定
  不是預設值時才會加入，而且永遠不會存進建置。
- **階層路徑** 會顯示物件的路徑，旁邊的按鈕可複製它。
- **小數位數** 會四捨五入顯示的位置、旋轉與縮放數值。`-1` 會關閉四捨五入，滑桿最高到 6 位。
- **預設 UI** 會展開 Unity 自己的 Transform 檢視器。預製體覆寫只支援 IMGUI，因此該卡片是編輯覆寫的地方，而且在那裡只能使用
  基本功能。
