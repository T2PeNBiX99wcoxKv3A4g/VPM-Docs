# UPM 安裝器

**Tools &gt; YKYToolkit &gt; UPM Installer** 可在不離開編輯器的情況下安裝、移除與更新 UPM 套件。

## 左右兩欄

左欄是目前操作的套件清單；右欄存放已儲存的套件清單與產生器。

## 工具列

| 按鈕                          | 動作                                  |
|-------------------------------|---------------------------------------|
| 安裝                          | 安裝左側清單中的所有套件。            |
| 刪除                          | 移除左側清單中的套件。                |
| 更新                          | 查詢 registry，並加入有新版本的套件。 |
| 清除                          | 清空左側清單。                        |
| 檢查更新並升級所有 UPM 套件   | 升級所有已安裝的套件。                |
| 匯入至產生器                  | 把左側清單複製到右側的產生器。        |

按鈕文字會跟著[偏好設定](./Preferences.md)中選擇的語言；上表是繁體中文的名稱。

## 已儲存的套件清單

一組已儲存的清單有名稱，以及任意數量的 `name@version` 項目。

- 展開資料列即可開啟其 **套件** 摺疊區並編輯項目。
- **匯入** 會把選取的清單加入左欄。
- **刪除選取項目** 會移除它。
- 在資料列上按右鍵可複製成 JSON 或刪除。
- 清單以專案為單位存放在 `EditorPrefs`，因此重新啟動後仍在，但不會進入版本控制。

## 產生器

產生器是建立新儲存清單時的工作清單：加入套件項目，然後在 **套件清單名稱** 中輸入名稱並按下 **建立並複製**。清單會儲存並以
JSON 複製到剪貼簿，方便分享或提交到儲存庫。

## 套件版本的寫法

項目是 `packageName` 加上選用的 `version`。版本留空表示最新的相容版本；指定版本則會鎖定那個發行版。清單接受來自
registry、Git 與本機路徑的套件，與 UPM 相同。
