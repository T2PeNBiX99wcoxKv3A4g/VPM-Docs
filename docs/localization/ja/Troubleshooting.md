# トラブルシューティング

## テキストではなくキーが表示される

1. アセットにそのキーそのものの項目があるか。
2. アセットの `localizationID` が `[assembly: LocalizationPackage("...")]` 属性のものと同じか。
3. アセットのファイル名が言語 ID（`en-US`）になっていて、フォールバックが見つけられるか。
4. 要素が `UILocalize` を通してローカライズされているか。`new Label("label.x")` だけでは決して書き換わりません。

`unity:` キーに項目がまったくない場合も同じメッセージが記録されます。[Unity-Keys](Unity-Keys) を参照してください。

## テキストが空になる

`translate` が空の項目も翻訳済みとして扱われ、英語へのフォールバックは働きません。まず英語アセットを埋めてください。他の言語は自動的にそこへフォールバックします。

## ツールチップが空になる

ツールチップは **ツールチップを使う** がオンのときだけ読み込まれます。オフのときは保存されたツールチップは無視され、UI が読むのは `{key}:tooltip` の項目です。

## 言語選択が空になる

言語一覧は同じ ID を共有するアセットから作られます。すべての言語アセットに同じ `localizationID` を設定し、ファイル名を言語 ID にしてください。

## 変更が反映されない

翻訳アセットを変更すると、最後の編集から 250 ms 後にデータが再読み込みされます。コンソールにカスタムインスペクターの例外が出ている場合、再読み込みがスキップされた可能性があります。**Tools > Localization > Reload Localizations** を実行してください。

## インポートで何も置き換わらない

インポートはキー単位でマージします。アセットにしかない項目は残り、ファイルにあるキーだけが更新されます。ファイルの `msgid`/キーがアセットと同じか確認してください。

## 翻訳の入力中にエディタが重い

インスペクターは再読み込みと検索を遅延させています。アセットが多いプロジェクトでまだ重く感じる場合は、毎フレームアセットを更新するスクリプトがないか確認してください。`OnValidate` は変更ごとに 1 回実行され、再読み込みを 1 回だけ予約します（キー入力ごとではありません）。
