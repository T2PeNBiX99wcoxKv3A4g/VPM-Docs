# インスペクター

`BasicLocalization` アセットを開くと、1 つの言語を編集できます。

## 設定カード

- **ローカライゼーションID** - パッケージの全言語で共有する ID。
- **表示名** - 言語選択に表示される名前。
- **言語** - 同じ ID を持つすべてのパッケージで、このアセット（およびエディタ）が現在表示している言語。

選択 UI は既製の `LanguagePicker` コントロールです。切り替えると、開いているすべてのインスペクターとウィンドウが同時に更新されます。

## フォーマット変換

このフォールドにはサイドカーファイルを指定します。

| フィールド | 内容 |
| --- | --- |
| JSON ファイル | アセットの隣に書き出す、`key: text` 形式のフラットなオブジェクト。 |
| PO ファイル | Gettext ファイル。キーごとに `msgid`/`msgstr` の組を 1 つ持ちます。 |

`…` ボタンはディスク上のファイルをアセットの隣にコピーします。**エクスポート** は現在のアセットを書き出し、**インポート** はキー単位でファイルをマージします。2 つのフィールドに入れられるのは `TextAsset` と `LocalizationAsset` だけです。

## 翻訳リスト

リスト上部のツールバーには、検索フィールド、項目数、追加/削除ボタンがあります。

- 検索はキー、テキスト、ツールチップで絞り込みます。入力が止まってから実行されます。
- 絞り込み中は項目数が `filtered/total` で表示されます。
- **+** は末尾に空の項目を追加し、**-** は選択中の項目を削除します。
- 行を右クリックすると、コピー、貼り付け、削除ができます。
- 行をドラッグして並べ替えられます（絞り込み中は不可）。

## 翻訳行

| フィールド | 備考 |
| --- | --- |
| 翻訳ID | キー（例: `label.my_window.title`）。 |
| 翻訳 | テキスト。複数行可。 |
| ツールチップを使う | オンにするとツールチップを保存し、下の 2 つのフィールドが表示されます。 |
| ツールチップの接尾辞 | ツールチップキーの接尾辞。既定は `:tooltip`。 |
| ツールチップ | ツールチップのテキスト。 |

**コピー** は項目全体を JSON としてクリップボードに入れ、**ペースト** はコピーした項目を行に書き戻します。貼り付けボタンは、クリップボードに項目があるときだけ有効になります。

## スクリプトアイコン

`BasicLocalization` と `BasicTranslate` は専用のスクリプトアイコン（`Runtime/Icons`）を持っています。SVG が元データで、Unity が読み込むのは 256 px の PNG です。
