# 检视器

打开一个 `BasicLocalization` 资源即可编辑一种语言。

## 设置卡片

- **ローカライゼーションID** - 包内所有语言共用的 id。
- **表示名** - 语言选择器中显示的名称。
- **言語** - 当前在所有使用相同 id 的包中显示的语言（本站与编辑器都是如此）。

选择器就是现成的 `LanguagePicker` 控件；切换它会同时更新所有已打开的检视器和窗口。

## 格式转换

该折叠面板用于管理附属文件：

| 字段 | 内容 |
| --- | --- |
| JSON ファイル | 与资源一起导出的扁平 `key: text` 对象。 |
| PO ファイル | Gettext 文件，每个键一对 `msgid`/`msgstr`。 |

`…` 按钮会把磁盘上的文件复制到资源旁边。**Export** 写出当前资源，**Import** 按键把文件合并回来。这两个字段只接受 `TextAsset` 和 `LocalizationAsset` 文件。

## 翻译列表

列表上方的工具栏包含搜索框、条目数以及添加/删除按钮。

- 搜索按键、文本或工具提示过滤，在你停止输入后才执行。
- 过滤生效时，计数显示为 `filtered/total`。
- **+** 在末尾添加一个空条目；**-** 删除所选条目。
- 右键点击某一行可以复制、粘贴和删除。
- 拖动行可以调整顺序（仅在未启用过滤时可用）。

## 翻译行

| 字段 | 说明 |
| --- | --- |
| 翻訳ID | 键，例如 `label.my_window.title`。 |
| 翻訳 | 文本，支持多行。 |
| ツールチップを使う | 开启后保存工具提示，下面的两个字段才会出现。 |
| ツールチップの接尾辞 | 工具提示键的后缀，默认为 `:tooltip`。 |
| ツールチップ | 工具提示文本。 |

**コピー** 把整条记录以 JSON 形式放入剪贴板，**ペースト** 把复制来的记录写回该行。当剪贴板中存在记录时，粘贴按钮才可用。

## 脚本图标

`BasicLocalization` 和 `BasicTranslate` 各自带有脚本图标（`Runtime/Icons`）。SVG 是源文件，Unity 实际导入的是 256 px 的 PNG。
