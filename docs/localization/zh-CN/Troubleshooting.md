# 故障排除

## UI 显示的是键而不是文本

1. 资源中是否有该确切键的条目？
2. 资源的 `localizationID` 是否与 `[assembly: LocalizationPackage("...")]` 特性中的 id 相同？
3. 资源的文件名是否是语言 id（`en-US`），以便回退时能找到它？
4. 该元素是否通过 `UILocalize` 进行了本地化？仅用 `new Label("label.x")` 创建的元素永远不会被重写。

当 `unity:` 键完全没有对应条目时，也会记录同样的消息——参见 [Unity-Keys](Unity-Keys)。

## 文本为空

`translate` 为空的条目会被视为已翻译：英语回退不会生效。请先填写英语资源；其他语言会自动回退到它。

## 工具提示为空

只有打开 `useTooltip` 时才会加载工具提示。否则已存储的工具提示会被忽略，UI 读取的是 `{key}:tooltip` 条目。

## 语言选择器为空

语言列表由共享同一 id 的资源构建。给每个语言资源设置相同的 `localizationID`，并以语言 id 命名文件。

## 更改没有生效

修改翻译资源后，会在最后一次编辑的 250 ms 之后重新加载数据。如果控制台显示来自自定义检视器的异常，重新加载可能已被跳过；此时运行 **Tools > Localization > Reload Localizations**。

## 导入没有替换任何内容

导入按键合并：仅存在于资源中的条目会被保留，只有文件中出现的键会被更新。请检查文件使用的 `msgid`/键与资源是否一致。

## 输入翻译时编辑器很卡

检视器会对重新加载和搜索做防抖处理。如果包含大量资源的项目仍然很慢，请检查是否有脚本在每帧更新资源；`OnValidate` 每次更改运行一次并只安排一次重新加载，而不是每次按键都安排一次。
