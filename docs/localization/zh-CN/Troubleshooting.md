# 故障排查

## UI 显示键而不是文本

1. 资源中是否有这个确切键的条目？
2. 资源的 `localizationID` 是否与 `[assembly: LocalizationPackage("...")]` 特性中的 id 相同？
3. 资源的文件名是否是语言 id（`en-US`），从而让回退能够找到它？
4. 该元素是否通过 `UILocalize` 本地化？直接 `new Label("label.x")` 而没有经过本地化的标签永远不会被重写。

当 `unity:` 键完全没有对应条目时，也会记录同样的消息，参见 [Unity-Keys](Unity-Keys)。

## 文本为空

`translate` 为空的条目仍算作已翻译，此时不会启用英文回退。请先填写英文资源；其他语言会自动回退到它。

## 工具提示为空

只有在开启 **ツールチップを使う** 时才会加载工具提示。否则已保存的工具提示会被忽略，UI 实际读取的是 `{key}:tooltip` 条目。

## 语言选择器为空

语言列表由共用同一 id 的资源构建。请为每个语言资源设置相同的 `localizationID`，并以语言 id 命名文件。

## 修改没有生效

修改翻译资源后，数据会在最后一次编辑的 250 ms 后重新加载。如果控制台显示来自自定义检视器的异常，重新加载可能被跳过；此时请运行 **Tools > Localization > Reload Localizations**。

## 导入没有替换任何内容

导入按键合并：仅存在于资源中的条目会保留，只有文件中存在的键才会被更新。请检查文件使用的 `msgid`/键是否与资源一致。

## 输入翻译时编辑器变慢

检视器会对重新加载和搜索做防抖处理。如果资源很多的项目仍然感觉卡顿，请检查是否有脚本在每帧更新资源；`OnValidate` 每次变更只调度一次重新加载，而不是每次按键一次。
