# 疑難排解

## UI 顯示鍵而不是文字

1. 資產中是否有這個確切鍵的項目？
2. 資產的 `localizationID` 是否與 `[assembly: LocalizationPackage("...")]` 屬性中的 ID 相同？
3. 資產的檔名是否是語言 ID（`en-US`），讓後備機制能找到它？
4. 元素是否透過 `UILocalize` 在地化？單純 `new Label("label.x")` 而沒有經過在地化的標籤永遠不會被改寫。

當 `unity:` 鍵完全沒有對應項目時，也會記錄同樣的訊息 - 詳見 [Unity 鍵](Unity-Keys)。

## 文字是空的

`translate` 為空的項目仍算已翻譯：不會啟用英文後備。請先填好英文資產，其他語言會自動後備到它。

## 工具提示是空的

只有在 **ツールチップを使う** 開啟時才會載入工具提示。否則已儲存的工具提示會被忽略，UI 實際讀取的是 `{key}:tooltip` 條目。

## 語言選擇器是空的

語言清單是由共用相同 ID 的資產建立。請讓每份語言資產都有相同的 `localizationID`，並以語言 ID 命名檔案。

## 變更沒有顯示出來

修改翻譯資產後，資料會在最後一次編輯的 250 ms 之後重新載入。如果主控台顯示來自自訂檢視器的例外，重新載入可能已被跳過；請執行 **Tools > Localization > Reload Localizations**。

## 匯入沒有取代任何內容

匯入會依鍵合併：只存在於資產中的項目會保留，只有檔案中存在的鍵才會更新。請確認檔案使用的 `msgid`／鍵與資產一致。

## 輸入翻譯時編輯器變慢

檢視器會對重新載入與搜尋做防抖處理。如果資產眾多的專案仍然覺得慢，請確認沒有腳本每幀都在更新資產；`OnValidate` 每次變更只會排程一次重新載入，而不是每敲一個鍵一次。
