# 疑難排解

## UI 顯示的是鍵而不是文字

1. 資產中是否有這個完整鍵的項目？
2. 資產的 `localizationID` 是否與 `[assembly: LocalizationPackage("...")]` 屬性中的 ID 相同？
3. 資產的檔名是否就是語言 ID（`en-US`），讓後備機制找得到它？
4. 元素是否透過 `UILocalize` 在地化？單純的 `new Label("label.x")` 沒有經過它，永遠不會被改寫。

當 `unity:` 鍵完全沒有項目時，也會記錄同樣的訊息 —— 請見 [Unity-Keys](Unity-Keys)。

## 文字是空的

`translate` 為空的項目仍算已翻譯：不會啟用英文後備。請先填好英文資產，其他語言會自動以它為後備。

## 工具提示是空的

只有開啟 `useTooltip` 時才會載入工具提示。否則儲存的工具提示會被忽略，而 UI 讀取的是 `{key}:tooltip` 項目。

## 語言選擇器是空的

語言清單是由共用同一個 ID 的資產組成的。請讓每個語言資產都有相同的 `localizationID`，並以語言 ID 命名檔案。

## 變更沒有顯示出來

變更翻譯資產後，會在最後一次編輯的 250 ms 後重新載入資料。若主控台顯示自訂檢視器拋出的例外，重新載入可能已被略過；請執行
**Tools > Localization > Reload Localizations**。

## 匯入沒有取代任何內容

匯入是依鍵合併：只存在於資產中的項目會保留，只有檔案中存在的鍵會被更新。請確認檔案使用的 `msgid`／鍵與資產相同。

## 輸入翻譯時編輯器很慢

檢視器會對重新載入與搜尋做延遲處理。若資產很多的專案仍然很慢，請確認沒有腳本每幀都更新資產；`OnValidate`
每次變更只會排程一次重新載入，而不是每按一鍵一次。
