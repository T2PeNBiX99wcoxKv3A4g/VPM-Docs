# UPM 安装器

**Tools &gt; YKYToolkit &gt; UPM Installer** 可以在不离开编辑器的情况下安装、删除和更新 UPM 包。

## 两栏布局

左栏是当前操作使用的包列表；右栏存放已保存的包列表以及列表生成器。

## 工具栏

| 按钮                         | 操作                                   |
|------------------------------|----------------------------------------|
| 安装                         | 安装左栏中的所有包。                   |
| 删除                         | 删除左栏中的包。                       |
| 更新                         | 查询注册表，并把有新版本的包加入列表。 |
| 清除                         | 清空左栏。                             |
| 检查更新并升级所有 UPM 包    | 升级所有已安装的包。                   |
| 导入到生成器                 | 把左栏内容复制到右侧的生成器。         |

按钮文字会跟随 [首选项](./Preferences.md) 中选择的语言；上面的名称是中文界面的文字。

## 已保存的包列表

每个已保存的列表都有一个名称，以及任意数量的 `name@version` 条目。

- 展开某一行即可打开它的 **包** 折叠区并编辑其中的条目。
- **导入** 把选中的列表添加到左栏。
- **删除所选** 移除该列表。
- 右键点击某一行，可以将其复制为 JSON 或删除。
- 列表按项目存储在 `EditorPrefs` 中，因此重启后仍然存在，但不会进入版本控制。

## 生成器

生成器是用于新建已保存列表的工作区：添加包条目，然后在 **包列表名称** 中输入名称并按下 **创建并复制**。该列表会被保存，并以
JSON 形式复制到剪贴板，因此可以分享或提交到仓库。

## 包版本号的写法

条目由 `packageName` 加上可选的 `version` 组成。版本留空表示最新的兼容版本；指定版本则会锁定该确切发行版。与 UPM
一样，列表接受来自注册表、Git 和本地路径的包。
