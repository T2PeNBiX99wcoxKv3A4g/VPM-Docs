# 导入监视器

**Tools &gt; YKYToolkit &gt; Import Watcher** 会记录 Unity 运行时导入的内容：资源、它来自哪个包、文件扩展名以及导入是否成功。

## 日志

该窗口每次编辑器运行对应一个会话。左栏列出该会话的日期，中间一栏列出导入时间，选中条目后右侧显示它的详细信息。

- **搜索** 按路径或包过滤日志。
- **刷新** 重新读取当前会话。
- **清除** 在确认后清空导入日志。
- **设置** 打开下文所述的设置窗口。
- 每个日期行会显示该日期下有多少条记录。
- 右键点击某一行，可以复制路径或将其移除。

## 高亮

导入的资源会在 Project 窗口中着色一小段时间，这样即使不看日志也能跟上一大批导入：

- **高亮颜色** 是覆盖在资源上的那层颜色。
- **高亮持续时间** 是它停留的时间，单位为毫秒；默认为 120，滑块最大到 500。
- **文件扩展名的高亮颜色** 让每个扩展名使用各自的颜色，因此 `.unitypackage` 的导入与 `.cs` 文件看起来不同。列表可以重新排序，
  **恢复默认值** 会还原随包提供的配色；没有对应条目的扩展名使用默认颜色。

图标视图会用扩展名颜色为整个单元格描边，列表视图则在行下画一条下划线。接收到文件的文件夹也会被高亮，并且颜色会逐渐淡出，而不是立刻消失。

## 设置

**Tools &gt; YKYToolkit &gt; Import Watcher Settings** 会打开一个包含这些设置的小窗口；相同的值也位于
**Edit &gt; Preferences &gt; YKY Toolkit &gt; Import Watcher**。

| 设置                     | 作用                                                   |
|--------------------------|--------------------------------------------------------|
| 高亮颜色                 | 在 Project 窗口中覆盖在导入资源上的颜色。               |
| 高亮持续时间             | 高亮停留的时间，单位为毫秒。                           |
| 最大历史会话数           | 历史记录保留的编辑器会话数量。                         |
| 文件扩展名的高亮颜色     | 高亮使用的按扩展名颜色，带计数与重置按钮。             |

小节标题旁的重置按钮会恢复随包提供的值。所有内容都按用户存储在 `EditorPrefs` 中，因此不会被提交。

## 删除历史

Unity 删除资源时不会有任何提示。删除历史窗口会列出本次会话中被删除（或删除后又重新创建）的路径，以便找回被删掉的 `.meta`
文件或整个被移动的文件夹。通过 **Tools &gt; YKYToolkit &gt; Delete History** 打开它；[首选项](./Preferences.md) 中的
**最大记录数** 会限制保留的条目数量。
