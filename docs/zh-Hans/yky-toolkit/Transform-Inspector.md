# Transform 检视器

工具包用一个能做算术运算、对齐对象并锁定变换的检视器替换了默认的 Transform 检视器。所有数值依然会经过 `Undo`，因此 `Ctrl+Z`
可以恢复之前的变换。

## 局部空间与世界空间

**局部空间** 和 **世界空间** 两张卡片分别显示该空间下的位置、旋转和缩放。每张卡片都带有复制、粘贴、随机和重置按钮，作用于整张卡片；每一行也重复同样的操作，作用于该行自己的属性。缩放行上的链接按钮用于切换等比约束。

多选时会显示共同的值，不一致的地方显示为 `—`。

## 表达式

每个字段都接受表达式，而不只是数字：

```
2 + 3          -> 5
10 / 4         -> 2.5
1.5 * 2        -> 3
```

按 Enter 应用：结果会写入所有选中对象，字段随后恢复为普通数字。输入过程中，字段下方会出现匹配的表达式列表；用 `↑`/`↓`
选择，按 Enter 或 Tab 插入。单独的 `Tab` 仍然在各字段之间切换。

## 帮助

**Tools &gt; YKYToolkit &gt; Transform Expression Help** 会打开速查表，其中列出每个表达式、它的签名和一个示例，并按基本算术、多选时的排序以及随机值分组。搜索框可以按语法、别名或说明过滤，点击任意一行会把它的示例复制到剪贴板。

## 剪贴板

| 操作                  | 效果                                                          |
|-----------------------|---------------------------------------------------------------|
| 复制 / 粘贴（标题栏） | 该卡片的位置、旋转和缩放。                                    |
| 行内按钮              | 该行的单项属性。                                              |
| 右键点击字段          | **复制欧拉角**、**复制四元数** 以及 Unity 自带的菜单项。      |

剪贴板使用 Unity 自己的 `Vector3(…)` 和 `Quaternion(…)` 文本，因此这些值也能粘贴到 Unity 默认字段以及其他工具中。

## 对齐

**对齐模式** 决定 **对齐到地面** 使用的参考点：轴心、对象边界的底部或中心。

- **对齐到父级** 把对象移到父级的位置。
- **对齐到地面** 向下射线检测到第一个既不是该对象本身也不是其子级的碰撞体（忽略触发器与 `Ignore Raycast` 层），并把对象放在命中点上。
- **清除父级** 保持世界位置不变并移除父级。在预制体阶段中不可用。

## 其他

- **锁定变换** 会禁用该对象在检视器中的所有字段和操作。锁定状态按对象存储在隐藏的 `EnhancedTransformSettings` 组件中，该组件只在有非默认设置时添加，并且永远不会保存进构建。
- **层级路径** 显示对象的路径，旁边的按钮可以复制它。
- **小数位数** 会四舍五入显示的位置、旋转和缩放数值。`-1` 关闭舍入，滑块最大到 6 位。
- **默认 UI** 会展开 Unity 自带的 Transform 检视器。预制体覆盖只支持 IMGUI，因此该卡片是编辑覆盖的地方，并且在那里只能使用基本功能。
