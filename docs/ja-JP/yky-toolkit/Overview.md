# 概要

YKY Toolkit は、日常の Unity 作業のためのエディタウィンドウとコンテキストメニュー操作の詰め合わせです。パッケージのインストール、インポートの監視、メモリの監視、キャッシュの掃除、Transform
の編集などを行います。

すべて **Tools &gt; YKYToolkit** の下にあり、コンテキスト操作は **GameObject &gt; YKYToolkit**、**Assets &gt; YKYToolkit**
、およびコンポーネントのコンテキストメニューにあります。[機能一覧](./Features.md) にすべてを載せています。

## 含まれるもの

| ウィンドウ | 内容 |
|------------|------|
| [UPM インストーラー](./UPM-Installer.md) | UPM パッケージのインストール、削除、更新と、再利用できるパッケージリストの管理。 |
| [インポートウォッチャー](./Import-Watcher.md) | 何が、いつ、どこからインポートされたかを記録し、拡張子ごとに新しいアセットを強調表示します。 |
| Delete History | セッション中に削除・再作成されたアセットを一覧します。 |
| Unity Resource Monitor | エディタプロセスのメモリと CPU をリアルタイム表示します。 |
| [ツール](./Tools.md) | キャッシュの掃除、アセットのバックアップ、GUID のコピー、コンストレイントの変換、コンポーネントのコピー/貼り付け。 |
| [Transform インスペクター](./Transform-Inspector.md) | 数式、整列、クリップボード、ロックを備えた拡張 Transform インスペクター。 |
| Transform Expression Help | 式の構文のチートシート。検索とコピーできる例があります。 |
| [環境設定](./Preferences.md) | 言語、アクセントカラー、削除保護、履歴の上限。 |

ウィンドウの文字列は翻訳されます。言語の選択は [環境設定](./Preferences.md) ページの最初のカードにあります。

## 依存関係

| パッケージ | 理由 |
|------------|------|
| `io.github.ykysnk.utils` | インスペクターの基底クラス、GUI ヘルパー、UPM クライアント。 |
| `io.github.ykysnk.localization` | エディタの文字列。ウィンドウは翻訳されています。 |

どちらも VPM 依存で、自動的に解決されます。`jp.lilxyzw.editortoolbox` は任意です。入っている場合、ツールキットは
`.unitypackage` ファイルのインポートにそのパッケージインポーターを使います。
