# インポートウォッチャー

**Tools &gt; YKYToolkit &gt; Import Watcher** は、実行中に Unity
がインポートした内容を記録します。アセット、それが属するパッケージ、ファイル拡張子、インポートが成功したかどうかです。

## ログ

ウィンドウはエディタの起動ごとに 1 つのセッションを保持します。各行には時刻、アセットパス、状態が表示されます。

- **検索** はパスまたはパッケージでログを絞り込みます。
- リスト下部の追加/削除ボタンで履歴のサイズを調整します。
- 行を右クリックすると、パスをコピーするか削除できます。
- **Refresh** は現在のセッションを読み直し、**Delete History** は削除されたアセットを一覧するウィンドウを開きます。

## 色

ファイル拡張子ごとに色を設定できるので、`.unitypackage` のインポートを `.cs` ファイルから見分けられます。

1. **Import Watcher Settings** を開きます。
2. 拡張子を追加し、色を選びます。
3. 次のインポートから、ログとヒエラルキーの強調表示にその色が使われます。

## 設定

| 設定         | 効果                                 |
|--------------|--------------------------------------|
| Max sessions | 履歴に保持するエディタセッション数。 |
| Colors       | ログの拡張子ごとの色。               |

設定はプロジェクトの `EditorPrefs` にあり、コミットされません。

## 削除履歴

Unity はアセットを誰にも告げずに削除します。Delete History ウィンドウは、セッション中に削除された（または削除されて再作成された）パスを一覧するので、消えた
`.meta` や移動したフォルダを見つけ直せます。**Tools &gt; YKYToolkit &gt; Delete History** で開きます。
