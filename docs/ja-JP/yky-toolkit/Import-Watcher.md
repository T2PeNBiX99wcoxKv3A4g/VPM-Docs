# インポートウォッチャー

**Tools &gt; YKYToolkit &gt; Import Watcher** は、実行中に Unity
がインポートした内容を記録します。アセット、それが属するパッケージ、ファイル拡張子、インポートが成功したかどうかです。

## ログ

ウィンドウはエディタの起動ごとに 1 つのセッションを保持します。左の列にはセッションの日付、中央の列にはインポート時刻が並び、選択した項目の詳細が右に表示されます。

- **検索** はパスまたはパッケージでログを絞り込みます。
- **再読み込み** は現在のセッションを読み直します。
- **クリア** は確認のあとインポートログを空にします。
- **設定** は後述の設定ウィンドウを開きます。
- 各日付の行には、その日の記録数が表示されます。
- 行を右クリックすると、パスをコピーするか削除できます。

## ハイライト

インポートされたアセットは一瞬プロジェクトウィンドウに色付けされるので、大きなインポートでもログを見続けずに追えます:

- **ハイライト色** はアセットの上に重ねて描かれる色です。
- **ハイライトの持続時間** はハイライトが残る時間（ミリ秒）です。既定値は 120 で、スライダーは 500 で止まります。
- **ファイル拡張子のハイライト色** は拡張子ごとに色を割り当てるので、`.unitypackage` のインポートが `.cs` ファイルと違って見えます。リストは並べ替えられ、**既定値に戻す** で同梱のセットに戻せます。項目のない拡張子は既定の色を使います。

アイコン表示ではセル全体が拡張子の色で囲まれ、リスト表示では代わりに行の下に下線が引かれます。ファイルを受け取ったフォルダも強調表示され、色はすぐに消えるのではなく徐々に薄れます。

## 設定

**Tools &gt; YKYToolkit &gt; Import Watcher Settings** を開くと、これらの設定を集めた小さなウィンドウが開きます。同じ値は
**Edit &gt; Preferences &gt; YKY Toolkit &gt; Import Watcher** にもあります。

| 設定 | 効果 |
|------|------|
| ハイライト色 | プロジェクトウィンドウでインポートされたアセットに重ねて描かれる色。 |
| ハイライトの持続時間 | ハイライトが残る時間（ミリ秒）。 |
| 最大履歴セッション数 | 履歴が保持するエディタセッション数。 |
| ファイル拡張子のハイライト色 | ハイライトが使う拡張子ごとの色。件数表示とリセット付き。 |

セクション見出しの横にあるリセットボタンで同梱の値に戻ります。すべてユーザーごとに `EditorPrefs` へ保存されるので、コミットされません。

## 削除履歴

Unity はアセットを誰にも告げずに削除します。Delete History ウィンドウは、セッション中に削除された（または削除されて再作成された）パスを一覧するので、消えた
`.meta` や移動したフォルダを見つけ直せます。**Tools &gt; YKYToolkit &gt; Delete History** で開きます。[環境設定](./Preferences.md)
の **最大記録数** が保持する項目数の上限です。
