# 環境設定

**Tools &gt; YKYToolkit &gt; Preferences** でツールキットの設定を開きます。同じ設定は **Edit &gt; Preferences &gt; YKY Toolkit**
にもあります。ユーザーごとに `EditorPrefs` へ保存されるので、プロジェクトではなく Unity のインストールに付いて回り、コミットされません。

## 言語

上部の選択でツールキットのウィンドウの言語を切り替えます。英語、日本語、簡体字中国語、繁体字中国語です。各ウィンドウの文字列はすぐに切り替わり、**Tools
&gt; YKYToolkit** の下のメニューパスは英語のままです。

## 外観

| 設定 | 効果 |
|------|------|
| アクセントカラー | ツールキットと Transform インスペクターの見出し、強調、ボタンに使われる色。 |

セクション見出しのリセットボタンで同梱のアクセントカラーに戻ります。

## 一般

| 設定 | 効果 |
|------|------|
| 非同期コンパイルを許可 | エディタを動かしたまま Unity がバックグラウンドでシェーダーをコンパイルできるようにします。既定でオンです。 |
| 選択項目削除の警告ウィンドウ | **Delete Selected** がアセットを削除する前に確認ダイアログを表示します。 |
| Discord リッチプレゼンスを有効にする | Discord のステータスにプロジェクトと現在のシーンを表示します。既定でオンです。 |

リセットボタンは 3 つのトグルすべてを戻します。

## 削除保護

`Assets` と `Packages` は常に保護されます。**追加で保護するディレクトリ** はさらに追加します。`+` を押してパスを入力すると、削除操作はそれを含む選択を拒否し、削除する代わりにブロックしたディレクトリを一覧します。

リスト下部で項目を追加・削除でき、そのリセットボタンは追加したディレクトリを消します。

## 削除履歴

| 設定 | 効果 |
|------|------|
| 最大記録数 | 削除履歴が保持する削除済みアセットの数（1〜1000）。 |

## インポートウォッチャー

| 設定 | 効果 |
|------|------|
| ハイライト色 | プロジェクトウィンドウでインポートされたアセットに重ねて描かれる色。 |
| ハイライトの持続時間 | ハイライトが残る時間（ミリ秒、最大 500）。 |
| 最大履歴セッション数 | インポート履歴が保持するエディタセッション数（1〜1000）。 |
| ファイル拡張子のハイライト色 | ハイライトが使う拡張子ごとの色。件数表示とリセット付き。 |

これらは **Tools &gt; YKYToolkit &gt; Import Watcher Settings** と同じ値です。リセットボタンで戻せます。ハイライトが何をするかは
[インポートウォッチャー](./Import-Watcher.md) を参照してください。

## このページにないもの

Transform インスペクターはオブジェクトごとの値を自分で持ちます。**Transform をロック** と小数点以下の桁数は、ここではなくオブジェクトの隠しコンポーネントに保存されます。詳しくは
[Transform インスペクター](./Transform-Inspector.md) を参照してください。
