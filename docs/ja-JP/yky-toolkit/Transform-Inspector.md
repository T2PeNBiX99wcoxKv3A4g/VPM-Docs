# Transform インスペクター

ツールキットは既定の Transform インスペクターを、計算ができ、オブジェクトを整列でき、Transform をロックできるものに置き換えます。どの値も
`Undo` を通すので、`Ctrl+Z` で前の Transform に戻せます。

## ローカル座標系とワールド座標系

**ローカル座標系** と **ワールド座標系** の 2 つのカードが、その座標系での位置、回転、スケールを表示します。各カードにはカード全体に作用するコピー、貼り付け、ランダム、リセットのボタンがあり、各行にも同じ操作がそのプロパティ用に用意されています。スケール行のリンクボタンは比率の固定を切り替えます。

複数選択では共通の値を 1 度だけ表示し、値が異なる箇所は `—` になります。

## 式

どのフィールドも、数値だけでなく式を受け付けます:

```
2 + 3          -> 5
10 / 4         -> 2.5
1.5 * 2        -> 3
```

Enter を押すと適用されます。結果は選択中のすべてのオブジェクトに書き込まれ、フィールドは普通の数値に戻ります。入力中は一致する式の一覧がフィールドの下に表示され、`↑`/`↓`
で選び、Enter か Tab で挿入します。`Tab` だけなら通常どおりフィールド間を移動します。

## ヘルプ

**Tools &gt; YKYToolkit &gt; Transform Expression Help** を開くと、すべての式とその書式、例をまとめたチートシートが開きます。基本の四則演算、複数選択での並び順、ランダム値に分かれています。検索ボックスは構文、別名、説明で絞り込み、行をクリックするとその例がクリップボードにコピーされます。

## クリップボード

| 操作 | 効果 |
|------|------|
| コピー / 貼り付け（ヘッダー） | そのカードの位置、回転、スケール。 |
| 行のボタン | その行の 1 つのプロパティ。 |
| フィールドを右クリック | **オイラー角をコピー**、**クォータニオンをコピー**、および Unity 標準のメニュー項目。 |

クリップボードは Unity 標準の `Vector3(…)` と `Quaternion(…)` の文字列を使うので、Unity 既定のフィールドや他のツールにもそのまま貼り付けられます。

## 整列

**整列モード** は **地面に合わせる** が使う基準（ピボット、オブジェクトのバウンズの下端、または中心）を選びます。

- **親に合わせる** はオブジェクトを親の位置へ移動します。
- **地面に合わせる** は、オブジェクト自身とその子以外で最初に当たったコライダーへ下向きにレイキャストし、トリガーと `Ignore Raycast`
  レイヤーを無視して、当たった位置にオブジェクトを置きます。
- **親を解除** はワールド位置を保ったまま親を外します。プレハブステージでは無効です。

## その他

- **Transform をロック** はそのオブジェクトのインスペクターのすべてのフィールドと操作を無効にします。ロックはオブジェクトごとに隠しコンポーネント
  `EnhancedTransformSettings` に保存され、設定が既定値でない間だけ追加され、ビルドには保存されません。
- **ヒエラルキーパス** はオブジェクトのパスを表示し、隣のボタンでコピーできます。
- **小数点以下の桁数（-1 で無効）** は位置、回転、スケールの表示値を丸めます。`-1` で丸めをやめ、スライダーは 6 桁までです。
- **デフォルトUI** は Unity 標準の Transform インスペクターを展開します。プレハブのオーバーライドは IMGUI しかサポートしないため、オーバーライドの編集はそのカードで行い、そこでは基本機能だけが使えます。
