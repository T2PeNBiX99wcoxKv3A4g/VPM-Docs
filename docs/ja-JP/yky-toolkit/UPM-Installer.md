# UPM インストーラー

**Tools &gt; YKYToolkit &gt; UPM Installer** は、エディタを離れずに UPM パッケージのインストール、削除、更新を行います。

## 2 つの列

左の列は現在の操作対象のパッケージリスト、右の列は保存済みのパッケージリストとリストメーカーです。

## ツールバー

| ボタン | 動作 |
|--------|------|
| インストール | 左のリストの全パッケージをインストールします。 |
| 削除 | 左のリストのパッケージを削除します。 |
| 更新 | レジストリに問い合わせ、新しいバージョンがあるパッケージを追加します。 |
| クリア | 左のリストを空にします。 |
| 更新を確認し、すべてのUPMパッケージをアップグレードする | インストール済みの全パッケージをアップグレードします。 |
| メーカーへインポート | 左のリストを右のメーカーにコピーします。 |

ボタンの文字列は [環境設定](./Preferences.md) で選んだ言語に従います。上の表は日本語の表記です。

## 保存済みパッケージリスト

保存済みリストは名前と、任意個の `name@version` 項目を持ちます。

- 行を展開すると **パッケージ** の折りたたみが開き、項目を編集できます。
- **インポート** は選択中のリストを左の列に追加します。
- **選択した項目を削除** はそれを削除します。
- 行を右クリックすると、JSON としてコピーするか削除できます。
- リストはプロジェクトごとに `EditorPrefs` へ保存されるので、再起動しても残りますがバージョン管理には入りません。

## メーカー

メーカーは新しい保存済みリストを作るための作業用リストです。パッケージ項目を追加し、**パッケージリスト名** に名前を入力して
**作成してコピー** を押します。リストは保存され、JSON としてクリップボードにもコピーされるので、共有したりリポジトリにコミットできます。

## パッケージバージョンの書き方

項目は `packageName` と任意の `version` です。バージョンが空なら互換性のある最新版、指定するとそのリリースに固定されます。UPM
と同様、レジストリ、Git、ローカルパスのパッケージを受け付けます。
