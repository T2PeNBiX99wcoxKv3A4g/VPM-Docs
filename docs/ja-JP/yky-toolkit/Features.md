# 機能一覧

ツールキットが追加するものを、表示される場所ごとにまとめました。詳細はリンク先のページにあります。

## ウィンドウ

- [**UPM インストーラー**](./UPM-Installer.md) — UPM パッケージのインストール、削除、更新。プロジェクトごとの
  パッケージリストの保存。リストを JSON としてコピーするメーカー。新しいバージョンのあるパッケージだけを追加する
  更新確認。
- [**インポートウォッチャー**](./Import-Watcher.md) — エディタセッションごとに、Unity がインポートしたアセットのログ。
  日付と時刻でまとめます。検索、再読み込み、クリア。存在しないアセットは赤で表示。
- [**Import Watcher Settings**](./Import-Watcher.md) — ハイライト色と持続時間、拡張子ごとの色、履歴のサイズ。
- [**Delete History**](./Import-Watcher.md) — セッション中に削除または再作成されたパス。パス、GUID、拡張子、
  時刻。どちらの値もコピーできます。設定できる記録数の上限。
- [**Unity Resource Monitor**](./Tools.md) — 100 ms ごとに更新される 7 つのカウンター。
- [**Transform Expression Help**](./Transform-Inspector.md) — すべての式を検索できるチートシート。クリックで
  コピーできる例付き。
- [**環境設定**](./Preferences.md) — 言語、アクセントカラー、一般のトグル、削除保護、2 つの履歴の上限。

## Tools メニュー

- **Clear Shader Cache** — Unity のコンパイル済みシェーダーキャッシュを削除します。
- **Force Clear Temp Files** — プロジェクトの `Temp` フォルダを削除します。Unity が再生成します。
- **Clear Empty Folder** — 確認と件数の表示のあと、空のフォルダを削除します。
- **Allow Async Compilation** — バックグラウンドのシェーダーコンパイル。チェックマークが現在の状態を示します。
- **Set Object and Tag** — 選択を通常のオブジェクトとエディタ専用のオブジェクトの間で切り替えます。
- **Discord SDK Initialize / Restart / Shutdown** — 任意のエディタ rich presence を制御します。

## Assets メニュー

- **Asset Backup** — 選択中のアセットをタイムスタンプ付きのバックアップフォルダにコピーします。
- **Asset GUID Copy** — 選択中のアセットの GUID をコピーします。
- **Delete Selected** — 確認ダイアログを経て削除し、パスを削除履歴に記録します。

## GameObject とコンポーネントのメニュー

- **Set Object and Tag** — オブジェクトを非アクティブにして `EditorOnly` タグを付け、以前のタグとアクティブ状態を
  記憶します。もう一度実行すると両方が元に戻ります。
- **Copy All Components** / **Paste All Components** — あるオブジェクトのすべてのコンポーネントを別のオブジェクトへ
  移します。
- **Paste All Components With Transform** — 同じことに加えて Transform も貼り付けます。
- **Copy Transform Tree** / **Paste Transform Tree** — Transform とコンポーネントごと階層全体をコピー/貼り付け
  します。
- **Convert Unity Constraint To VRC Constraint** / **Convert VRC Constraint To Unity Constraint** — 設定を保った
  まま 2 種類のコンストレイントを入れ替えます。
- **Delete Selected** — Assets メニューと同じ削除操作です。

## Transform インスペクター

既定の Transform インスペクターは、拡張されたものに置き換わります:

- **ローカル座標系** と **ワールド座標系** のカード。それぞれに位置、回転、スケールがあります。
- どのフィールドでも使える四則演算: `2 + 3`、`10 / 4`、`1.5 * 2`。結果は選択中のすべてのオブジェクトに
  適用されます。
- 入力中に式の候補を表示し、`↑`/`↓`、Enter、Tab で選べます。
- カード全体とプロパティ単体のコピー、貼り付け、ランダム、リセット。
- スケールのリンクボタンで比率の固定を切り替えます。
- 整列: 基準モード（ピボット、下端、中心）、**親に合わせる**、レイキャストによる **地面に合わせる**、
  **親を解除**。
- **Transform をロック** はそのオブジェクトのインスペクター全体を無効にします。
- コピーボタン付きの **ヒエラルキーパス**。
- 位置、回転、スケールの **小数点以下の桁数**（`-1` で丸めを無効）。
- **デフォルトUI** はプレハブのオーバーライド用に Unity 自身のインスペクターを展開します。
- 共通の値を表示し、値が異なる箇所は `—` になる複数選択編集。どの変更も `Undo` を通ります。

## プロジェクトウィンドウ

- インポートされたアセットはハイライト色で一瞬塗られ、フェードアウトします。
- ファイル拡張子ごとに色を設定でき、アイコン表示ではアイコンの枠として、リスト表示では下線として表示されます。
- ファイルを受け取ったフォルダも強調表示されます。

## エディタの動作

- **削除保護**: `Assets` と `Packages` は常に削除を拒否し、追加のディレクトリは
  [環境設定](./Preferences.md) で追加できます。
- **削除の確認**: ダイアログは削除されるものを一覧し、オフにもできます。
- **バックグラウンドのシェーダーコンパイル** はメニューからも環境設定からも切り替えられます。
- **Discord リッチプレゼンス** はプロジェクトと現在のシーンを表示し、完全にオフにできます。
- **翻訳されたウィンドウ**: 英語、日本語、簡体字中国語、繁体字中国語。環境設定で切り替えます。
- **アクセントカラー**: すべてのウィンドウと Transform インスペクターの見出し、強調、ボタンに使う 1 つの色。
