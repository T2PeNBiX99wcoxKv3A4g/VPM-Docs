# インスペクター

`BasicLocalization` アセットを開くと、1 つの言語を編集できます。インスペクターはパッケージ自身で翻訳されるため、
ラベルは選択中の言語に従います。このページではフィールドを役割で呼び、必要に応じて `BasicLocalization` /
`BasicTranslate` でのフィールド名を添えます。

## 設定カード

- **ローカライゼーション ID** (`localizationID`) - パッケージの全言語で共有する ID。
- **表示名** (`displayName`) - 言語選択に表示される名前。
- **言語** - この ID で選択中の言語。どのエディタウィンドウでも同じです。

選択 UI は既製の `LanguagePicker` コントロールです。切り替えると、開いているすべてのインスペクターとウィンドウが同時に更新されます。

## フォーマット変換

このフォールドにはサイドカーファイルを指定します。

| フィールド                 | 内容                                                                |
|----------------------------|---------------------------------------------------------------------|
| JSON ファイル (`jsonFile`) | アセットの隣に書き出す、フラットな `key: text` オブジェクト。       |
| PO ファイル (`poFile`)     | Gettext ファイル。キーごとに `msgid`/`msgstr` の組を 1 つ持ちます。 |

`…` ボタンはディスク上のファイルをアセットの隣にコピーします。**エクスポート** は現在のアセットを書き出し、**インポート**
は
キー単位でファイルをマージします。2 つのフィールドに入れられるのは `TextAsset`（JSON）と `LocalizationAsset`（PO）だけです。

## 翻訳リスト

リスト上部のツールバーには、検索フィールド、項目数、追加/削除ボタンがあります。

- 検索はキー、テキスト、ツールチップで絞り込みます。入力が止まってから実行されます。
- 絞り込み中は項目数が `filtered/total` で表示されます。
- 追加は末尾に空の項目を加え、削除は選択中の項目を削除します。
- 行を右クリックすると、コピー、貼り付け、削除ができます。
- 行をドラッグして並べ替えられます（絞り込み中は不可）。

## 翻訳行

| フィールド      | 備考                                                                    |
|-----------------|-------------------------------------------------------------------------|
| `key`           | キー（例: `label.my_window.title`）。                                   |
| `translate`     | テキスト。複数行可。                                                    |
| `useTooltip`    | オンにするとツールチップを保存し、下の 2 つのフィールドが表示されます。 |
| `tooltipSuffix` | ツールチップキーの接尾辞。既定は `:tooltip`。                           |
| `tooltip`       | ツールチップのテキスト。                                                |

コピーボタンは項目全体を JSON としてクリップボードに入れ、貼り付けはコピーした項目を行に書き戻します。貼り付けは、
クリップボードに翻訳項目があるときだけ有効になります。

## スクリプトアイコン

`BasicLocalization` と `BasicTranslate` は専用のスクリプトアイコン（`Runtime/Icons`）を持っています。SVG が元データで、
Unity が読み込むのは 256 px の PNG です。
