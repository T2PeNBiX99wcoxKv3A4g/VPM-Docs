# トラブルシューティング

## テキストではなくキーが表示される

1. アセットにそのキーそのものの項目がありますか？
2. アセットの `localizationID` は `[assembly: LocalizationPackage("...")]` 属性のものと同じですか？
3. アセットのファイル名は言語 ID（`en-US`）ですか？ フォールバックが見つけられるようにするためです。
4. 要素は `UILocalize` を通してローカライズされていますか？ `UILocalize` なしの `new Label("label.x")` は書き換えられません。

`unity:` キーに項目がまったくない場合も同じメッセージが記録されます。[Unity-Keys](./Unity-Keys.md) を参照してください。

## テキストが空になる

`translate` が空の項目も翻訳済みとして扱われるため、英語へのフォールバックは働きません。まず英語のアセットを埋めてください。
他の言語はそこへ自動的にフォールバックします。

## ツールチップが空になる

ツールチップは `useTooltip` がオンのときだけ読み込まれます。それ以外では保存されたツールチップは無視され、UI が読むのは
`{key}:tooltip` の項目です。

## 言語選択が空になる

言語の一覧は、同じ ID を共有するアセットから作られます。すべての言語アセットに同じ `localizationID` を与え、ファイル名を
言語 ID にしてください。

## 変更が反映されない

翻訳アセットを変更すると、最後の編集から 250 ms 後にデータが再読み込みされます。コンソールにカスタムインスペクターからの
例外が出ている場合、再読み込みが飛ばされた可能性があります。**Tools &gt; Localization &gt; Reload Localizations**
を実行してください。

## インポートで何も置き換わらない

インポートはキー単位でマージします。アセットにしかない項目は残り、ファイルにあるキーだけが更新されます。ファイルがアセットと
同じ `msgid`/キーを使っているか確認してください。

## 翻訳を入力しているとエディタが重い

インスペクターは再読み込みと検索を遅延させてまとめます。アセットの多いプロジェクトでまだ重い場合は、毎フレームアセットを更新する
スクリプトがないか確認してください。`OnValidate` は変更ごとに実行されますが、予約される再読み込みは 1 回で、キー入力ごとではありません。
