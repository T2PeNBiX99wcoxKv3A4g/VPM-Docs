# 导入监视器

**Tools > YKYToolkit > Import Watcher** 会记录 Unity 运行时导入的内容：资源、它来自哪个包、文件扩展名以及导入是否成功。

## 日志

该窗口每次编辑器运行对应一个会话。每一行显示时间、资源路径及其状态。

- **検索** 按路径或包过滤日志。
- 列表底部的添加/移除按钮用于控制历史记录的数量。
- 右键点击某一行，可以复制路径或将其移除。
- **Refresh** 重新读取当前会话；**Delete History** 打开列出已删除资源的窗口。

## 颜色

每个文件扩展名都可以有自己的颜色，这样 `.unitypackage` 导入就能与 `.cs` 文件区分开：

1. 打开 **Import Watcher Settings**。
2. 添加一个扩展名并选择颜色。
3. 从下一次导入开始，日志和层级高亮都会使用该颜色。

## 设置

| 设置         | 作用                         |
|--------------|------------------------------|
| Max sessions | 历史中保留多少个编辑器会话。 |
| Colors       | 日志中按扩展名区分的颜色。   |

这些设置保存在项目的 `EditorPrefs` 中，不会被提交。

## 删除历史

Unity 删除资源时不会有任何提示。删除历史窗口会列出本次会话中被删除（或删除后又重新创建）的路径，以便找回被删掉的 `.meta`
文件或整个被移动的文件夹。通过 **Tools > YKYToolkit > Delete History** 打开它。
