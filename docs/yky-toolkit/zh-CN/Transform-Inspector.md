# Transform 检视器

工具包用一个支持算术运算和对齐的检视器替换了默认的 Transform 检视器。

## 字段

每个字段都接受表达式，而不只是数字：

```
2 + 3          -> 5
10 / 4         -> 2.5
1.5 * 2        -> 3
```

按 Enter 应用；结果会写入变换，字段随后恢复为普通数字。`Tab` 照常在各字段之间切换。

## 剪贴板

| 操作 | 效果 |
| --- | --- |
| Copy | 复制世界空间或局部空间的位置、旋转和缩放。 |
| Paste | 把复制来的值写入当前选中对象。 |

每一行末尾的按钮用于复制或粘贴该单项属性。

## 对齐

对齐按钮会相对最后选中的对象移动选中内容：每个轴上的最小值、居中与最大值。这是在不输入坐标的情况下排齐一排对象最快的方式。

## 数据资源

`EnhancedTransformData` 保存一份具名的变换（位置、旋转、缩放以及目标对象）。检视器可以把当前变换保存为资源，之后再应用，这对于需要在场景之间共享的道具摆放规则很有用。

## 注意事项

- 检视器可同时作用于多个对象；不一致的值会显示为 `—`。
- 所有修改都会经过 `Undo`，因此 `Ctrl+Z` 可以恢复之前的变换。
- 表达式解析器与对齐字段使用的是同一个，因此在那些字段里 `0.5 + 0.5` 同样可用。
