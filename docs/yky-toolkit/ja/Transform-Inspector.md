# Transform インスペクター

ツールキットは既定の Transform インスペクターを、計算と整列ができるものに置き換えます。

## フィールド

どのフィールドも、数値だけでなく式を受け付けます。

```
2 + 3          -> 5
10 / 4         -> 2.5
1.5 * 2        -> 3
```

Enter を押すと適用され、結果が Transform に書き込まれ、フィールドは普通の数値に戻ります。`Tab` は通常どおりフィールド間を移動します。

## クリップボード

| 操作     | 効果                                                         |
|----------|--------------------------------------------------------------|
| コピー   | ワールドまたはローカルの位置、回転、スケールをコピーします。 |
| 貼り付け | コピーした値を現在の選択に書き込みます。                     |

各行の末尾のボタンは、その 1 つのプロパティだけをコピー/貼り付けします。

## 整列

整列ボタンは、最後に選択したオブジェクトを基準に選択を移動します。各軸の最小、中央、最大です。座標を入力せずにオブジェクトの列を揃える、最も速い方法です。

## データアセット

`EnhancedTransformData` は名前付きの Transform（位置、回転、スケール、対象オブジェクト）を保存します。インスペクターは現在の
Transform をアセットに保存し、後で適用できるので、シーン間で共有したい小物の配置ルールなどに便利です。

## 注意

- インスペクターは複数のオブジェクトを同時に扱います。値が混在する場合は `—` と表示されます。
- すべての編集は `Undo` を通すので、`Ctrl+Z` で前の Transform に戻せます。
- 式パーサーは整列フィールドと同じものなので、そこでも `0.5 + 0.5` が使えます。
