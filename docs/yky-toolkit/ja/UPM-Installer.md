# UPM インストーラー

**Tools > YKYToolkit > UPM Installer** は、エディタを離れずに UPM パッケージのインストール、削除、更新を行います。

## 2 つの列

左の列は現在の操作対象のパッケージリスト、右の列は保存済みのパッケージリストとリストメーカーです。

## ツールバー

| ボタン | 動作 |
| --- | --- |
| インストール (Install) | 左のリストの全パッケージをインストールします。 |
| 削除 (Remove) | 左のリストのパッケージを削除します。 |
| 更新 (Update) | レジストリに問い合わせ、新しいバージョンがあるパッケージを追加します。 |
| クリア (Clear) | 左のリストを空にします。 |
| 更新を確認し、すべてのUPMパッケージをアップグレードする (Check and upgrade) | インストール済みの全パッケージをアップグレードします。 |
| メーカーにインポートする (Import to maker) | 左のリストを右のメーカーにコピーします。 |

## 保存済みパッケージリスト

保存済みリストは名前と、任意個の `name@version` 項目を持ちます。

- 行を展開するとパッケージを確認・編集できます。
- **インポート** は選択中のリストを左の列に追加します。
- **選択した項目を削除** はそれを削除します。
- 行を右クリックすると、JSON としてコピーするか削除できます。
- リストはプロジェクトごとに `EditorPrefs` へ保存されるので、再起動しても残りますがバージョン管理には入りません。

## メーカー

メーカーは新しい保存済みリストを作るための作業用リストです。パッケージ項目を追加し、名前を入力して **作成してコピー** (Create and copy) を押します。リストは保存され、JSON としてクリップボードにもコピーされるので、共有したりリポジトリにコミットできます。

## パッケージバージョンの書き方

項目は `packageName` と任意の `version` です。バージョンが空なら互換性のある最新版、指定するとそのリリースに固定されます。UPM と同様、レジストリ、Git、ローカルパスのパッケージを受け付けます。
