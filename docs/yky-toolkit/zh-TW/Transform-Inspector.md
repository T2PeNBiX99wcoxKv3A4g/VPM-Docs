# Transform 檢視器

工具組會用一個能做算術與對齊的檢視器取代預設的 Transform 檢視器。

## 欄位

每個欄位都接受運算式，不只是數字：

```
2 + 3          -> 5
10 / 4         -> 2.5
1.5 * 2        -> 3
```

按下 Enter 套用；結果會寫入 transform，欄位則恢復成單純的數字。`Tab` 會照常在各欄位之間移動。

## 剪貼簿

| 動作 | 效果                             |
|------|----------------------------------|
| 複製 | 複製世界或區域位置、旋轉與縮放。 |
| 貼上 | 把複製的值寫到目前的選取項目。   |

每一列末端的按鈕可複製或貼上該單一屬性。

## 對齊

對齊按鈕會相對於最後選取的物件移動選取項目：每個軸上的最小值、中心與最大值。這是不用輸入座標就能把一排物件對齊的最快方式。

## 資料資產

`EnhancedTransformData` 會儲存具名的 transform（位置、旋轉、縮放與目標物件）。檢視器可以把目前的 transform
存成資產，之後再套用，對於需要在場景之間共用的道具擺放規則很有用。

## 備註

- 檢視器可同時作用於多個物件；混合值會顯示為 `—`。
- 所有編輯都會經過 `Undo`，因此 `Ctrl+Z` 可以還原先前的 transform。
- 運算式解析器與對齊欄位使用的是同一個，所以 `0.5 + 0.5` 在那裡也能用。
