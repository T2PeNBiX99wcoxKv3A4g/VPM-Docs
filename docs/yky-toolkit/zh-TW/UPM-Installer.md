# UPM 安裝器

**Tools > YKYToolkit > UPM Installer** 可在不離開編輯器的情況下安裝、移除與更新 UPM 套件。

## 左右兩欄

左欄是目前操作的套件清單；右欄存放已儲存的套件清單與清單製作器。

## 工具列

| 按鈕                                                                  | 動作                                  |
|-----------------------------------------------------------------------|---------------------------------------|
| インストール（安裝）                                                  | 安裝左側清單中的所有套件。            |
| 削除（移除）                                                          | 移除左側清單中的套件。                |
| 更新（更新）                                                          | 查詢 registry，並加入有新版本的套件。 |
| クリア（清除）                                                        | 清空左側清單。                        |
| 更新を確認し、すべてのUPMパッケージをアップグレードする（檢查並升級） | 升級所有已安裝的套件。                |
| メーカーにインポートする（匯入到製作器）                              | 把左側清單複製到右側的製作器。        |

## 已儲存的套件清單

一組已儲存的清單有名稱，以及任意數量的 `name@version` 項目。

- 展開資料列即可檢視與編輯其中的套件。
- **インポート** 會把選取的清單加入左欄。
- **選択した項目を削除** 會移除它。
- 在資料列上按右鍵可複製成 JSON 或刪除。
- 清單以專案為單位存放在 `EditorPrefs`，因此重新啟動後仍在，但不會進入版本控制。

## 製作器

製作器是建立新儲存清單時的工作清單：加入套件項目，然後輸入名稱並按下 **作成してコピー**（建立並複製）。清單會儲存並以 JSON
複製到剪貼簿，方便分享或提交到儲存庫。

## 套件版本的寫法

項目是 `packageName` 加上選用的 `version`。版本留空表示最新的相容版本；指定版本則會鎖定那個發行版。清單接受來自
registry、Git 與本機路徑的套件，與 UPM 相同。
