# 匯入監看器

**Tools > YKYToolkit > Import Watcher** 會記錄 Unity 執行期間匯入的內容：資產、它來自哪個套件、副檔名，以及匯入是否成功。

## 記錄

視窗會為每次編輯器執行保留一個工作階段。每一列顯示時間、資產路徑與狀態。

- **検索** 會依路徑或套件篩選記錄。
- 清單底部的加入／移除按鈕可控制歷史大小。
- 在資料列上按右鍵可複製路徑或移除。
- **Refresh** 會重新讀取目前的工作階段；**Delete History** 會開啟列出已刪除資產的視窗。

## 顏色

每個副檔名都可以有自己的顏色，讓 `.unitypackage` 的匯入與 `.cs` 檔案區分開來：

1. 開啟 **Import Watcher Settings**。
2. 加入副檔名並選擇顏色。
3. 從下一次匯入開始，記錄與階層中的醒目提示就會使用該顏色。

## 設定

| 設定 | 效果 |
| --- | --- |
| Max sessions | 歷史中保留多少個編輯器工作階段。 |
| Colors | 記錄中各副檔名的顏色。 |

設定存放在專案的 `EditorPrefs` 中，不會提交。

## 刪除歷史

Unity 刪除資產時不會通知任何人。刪除歷史視窗會列出本次工作階段中被刪除（或刪除後又重新建立）的路徑，讓被刪掉的 `.meta` 或搬移過的資料夾能夠找回來。**Tools > YKYToolkit > Delete History** 可開啟它。
